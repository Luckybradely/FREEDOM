# Mode Minimal – thème Shopify

Thème Shopify (Online Store 2.0) pour une boutique de prêt-à-porter : fiche produit avec galerie verticale,
pastilles de couleur, tailles, accordéons, bandeau défilant, tuiles numérotées, grande image, avis via appli.

## Installer
Shopify > Boutique en ligne > Thèmes > Ajouter un thème > Importer un fichier zip.

## Réglages utiles
- Couleurs des pastilles : Produits > option « Couleur » > choisir une couleur pour chaque valeur (nuancier Shopify).
- Badge « Best-seller » : ajouter le tag `best-seller` au produit.
- Sous-titre produit : métachamp `custom.subtitle`.
- Note étoilée et avis : installer une appli d'avis (Judge.me, Loox…) et ajouter son bloc dans la section « Avis clients ».
