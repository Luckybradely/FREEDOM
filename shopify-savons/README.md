# Savons Sage – thème Shopify

Thème Shopify (Online Store 2.0) pour une marque de savons pour peau mature.

## Mettre en ligne
- Zip : `zip -r savons.zip .` dans ce dossier, puis Shopify > Boutique en ligne > Thèmes > Ajouter un thème > Importer.
- Ou Shopify CLI : `shopify theme push` depuis ce dossier.

## À personnaliser (éditeur de thème Shopify)
Textes, couleurs, image de bannière, FAQ, menus (`main-menu`, `footer`).
